Фотографии для демонстрационных данных.

Положите сюда файлы с такими именами, и после команды
    python manage.py demo_data --clear
    python manage.py demo_data
они сами прикрепятся к публикациям ленты.

Если файла нет — ничего не сломается: вместо фотографии
рисуется цветная заглушка с буквой заголовка.

Для ленты (ширина 1200, высота 675 точек, формат JPG):
    feed-moda.jpg          дизайн одежды, швейная мастерская, ткани
    feed-obuchenie.jpg     учёба за ноутбуком, онлайн-занятие
    feed-arhitektura.jpg   архитектурный рисунок от руки, скетч
    feed-python.jpg        код на экране, занятие по программированию
    feed-sovety.jpg        рабочий стол, блокнот с планом, кофе
    feed-telefon.jpg       человек учится с телефона
